# 🚆 Train Ticket Booking System

A console-based **Train Ticket Booking System** developed using **Core Java** to demonstrate Object-Oriented Programming (OOP), JSON-based data persistence, secure password hashing, and service-oriented application design.

The application enables users to register, authenticate securely, search for trains, book and cancel tickets, and manage booking history through an interactive command-line interface.

---

## ✨ Features

- 🔐 Secure User Registration & Login
- 🔒 Password Encryption using BCrypt
- 🚆 Search Trains by Source & Destination
- 🎟️ Book Available Train Seats
- ❌ Cancel Existing Bookings
- 📖 View Booking History
- 💾 Persistent Storage using JSON Files
- ⚠️ Input Validation & Exception Handling

## ⚙️ How It Works

1. Register a new account.
2. Login using your credentials.
3. Search trains between two stations.
4. View available seats.
5. Book a seat.
6. View your booking history.
7. Cancel bookings whenever required.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Parthgarg53/Ticket-Booking.git
```

Navigate to the project

```bash
cd Ticket-Booking
```

Build the project

```bash
gradle build
```

Run the application

```bash
gradle run
```

Or simply execute `App.java` from IntelliJ IDEA.
